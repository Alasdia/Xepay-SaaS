API REST & WEBHOOKS

Intégrez Xepay à votre site ou app. SDK Node.js disponible. Accès API réservé aux plans Pro et Business.

// Créer un lien de paiement — Node.js SDK
const xepay = require('xepay-node');

const link = await xepay.paymentLinks.create({
  amount: 390,
  currency: 'usd', // 'xof' | 'usd' | 'eur'
  description: 'Fournisseur — Import textile',
  expires_in: '24h',
  notify_url: 'https://monsite.sn/webhook',
});

// → { id: '1de9d79e...', url: 'xepay.io/pay/...', status: 'pending' }
