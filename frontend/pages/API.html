Webhook API

Recevez des événements Xepay en temps réel.

Endpoint

POST https://api.alasdia.com/webhooks

Headers

X-Signature: sha256_signature
X-Epay-Event: payment.success
X-Epay-Timestamp: 1778878576
Content-Type: application/json

Webhook Secret

Votre secret apparaît lors de la création du webhook.

Signature

Xepay génère une signature HMAC SHA256 basée sur le body brut. 

signature = HMAC_SHA256(secret, raw_body)
Vérifiez toujours la signature avant de traiter un paiement.

Payload 

{
    "id": "evt_<event_id>",
    "timestamp": "<unix_timestamp>",
    "event": "payment.success",
    "data": {
      "amount": "<payment_amount>",
      "currency": "<payment_currency>",
      "user_id": "<user_id>",
      "link_id": "<link_id>"
    }
  }

Vérification (Node.js)

const crypto = require("crypto");

const signature = req.headers["x-signature"];

const expected = crypto
  .createHmac("sha256", SECRET)
  .update(JSON.stringify(req.body))
  .digest("hex");

if (expected !== signature) {
  throw new Error("Invalid signature");
}

res.status(200).json({
  received: true
});

Vérification (Python)

import hmac
import hashlib
import json

signature = request.headers.get("X-Signature")

expected = hmac.new(
    SECRET.encode(),
    json.dumps(body).encode(),
    hashlib.sha256
).hexdigest()

if expected != signature:
    raise Exception("Invalid signature")

return {
    "received": True
}

Retries automatiques

Xepay tente automatiquement de renvoyer les webhooks échoués jusqu’à 3 fois avec un court délai entre chaque tentative.

Réponses HTTP

Code Description
200 Webhook reçu
400 Signature invalide
500 Erreur serveur
